- A partial rollback's answer now names each message, and each uploaded file, it couldn't delete, with its conversation, after the counts of each kind. It used to give only the count of messages deleted, so the agent couldn't tell which were left.
- An answer the Slack client reads as a refusal but whose code isn't in Slack's form, such as a body that isn't JSON, is no longer taken as Slack refusing the call. A write's error says its outcome is unknown and how to check before trying again, and any other call's says to try again; an upload whose last step gets one keeps its comment for a rollback's note.
