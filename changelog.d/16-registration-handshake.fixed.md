- For `channels/register`, cache a descriptor only when the host's itemized answer accepts it (`accepted: true`), so `refresh_channels` can recover a refused, unanswered or timed-out registration. A descriptor the host refuses (`accepted: false`) is dropped even if an earlier answer accepted it, and closed if it was open. An omitted or malformed entry counts as unanswered and leaves its descriptor as it was. Each answer is logged once if it refuses or leaves out any channel, naming each with the host's reason where it gave one. An answer without itemized results is logged as accepting nothing. (#7)
- Discard stale listings and the host's answers to `channels/register` after a registration re-grant or a `refresh_channels` call. Discard a refresh listing if its host connection closed. (#8)
- `channels/open` with a non-empty `channelId` or any address field opens the channel named by `channelId` or `address.channelId`, or fails with "No matching channel found". Only a request naming nothing falls back to the first registered channel of the type.
- Refuse `state/rollback`, with `success: false` and a reason, while `slack.messaging` isn't active on the asking connection: before its initial policy, or when its grant doesn't cover that feature set. This includes a TCP client that reconnects with an earlier checkpoint and a later policy that withdraws the feature set on the same connection. (#8)
