- **Operators:** a `SLACK_DM_USERS` that is set but names no user (empty, only whitespace or only commas) now stops startup with exit 1 and one line naming it, as a `SLACK_SEND_CHANNELS` that names no conversation already did. Before, such a value let every DM past the whitelist, though the variable is a whitelist of who may DM. Set it to the user IDs whose DMs it lets through, or unset it so it filters none; `SLACK_DISABLE_DMS=true` drops every DM either way. Unchanged: an unset `SLACK_DM_USERS` filters no DM, and a list drops a DM, though not a group DM, from anyone it doesn't name.
