- When a Slack Web API request can't connect at any of the addresses it tries, the error text a call answers with now opens with why each attempt failed, such as `A request error occurred: connect ECONNREFUSED ::1:1; connect ECONNREFUSED 127.0.0.1:1`. Before, that opening read `A request error occurred: ` with nothing after it. The explanation after it is unchanged. This comes with axios 1.21.0, up from 1.18.1, which the lockfile now installs with follow-redirects 1.16.2, up from 1.16.0. Together they clear the 15 advisories `npm audit` reported against the earlier versions.
