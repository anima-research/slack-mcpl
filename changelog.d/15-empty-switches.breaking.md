- **Operators:** a `SLACK_DISABLE_DMS` or `SLACK_SUBSCRIBE_MEMBER_CHANNELS` that is set but empty, or only whitespace, now stops startup with exit 1 and one line naming it, as any other value but yes or no already did (#9). Before, an empty value read as off. To keep the switch off, unset it or set it to `false`. Unchanged: an unset switch is off, and `true`/`false`, `1`/`0` and `yes`/`no` read as before.
