- **Tool clients:** history/thread truncation notes are replaced by structured `pagination`; check `scanComplete`/`stopReason` and repeat the original query with `nextCursor` as `cursor` to continue. Numeric limits now require bounded integers, and unknown arguments refuse. The default `maxBytes` of 64 KiB can end a default read before its match count, with `byte_limit` and a cursor; a call that can't return even its first message fails, naming the `maxBytes` that fits it. A failed read now opens with "No messages were returned" instead of "Nothing was read". Existing tool names, default match counts, internal backscroll and `list_channels.writable` policy semantics are unchanged; no host upgrade or new OAuth scopes are required.
